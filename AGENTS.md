# AGENTS.md — Luan Guiron

## Princípio
Qualidade é padrão; estética é contextual. Nunca herdar automaticamente direção, estrutura, hero, ritmo ou componentes de outro projeto.

## Fluxo
Briefing → Creative Direction → Front-end → Anti-AI Review → Segment Fit Review → Cross-Project Similarity Review → acessibilidade/SEO/segurança/performance → QA → PR → deploy.

## Cross-Project Similarity Review
Antes de cada merge visual, comparar com projetos anteriores. Verificar hero, grid, densidade, tipografia, blocos, cores, navegação, CTAs e sensação geral. Semelhança não justificada pelo briefing é bloqueadora.

## Regras
Mobile-first, HTML semântico, foco visível, contraste, conteúdo factual, CTA claro e sem segredos. Backend apenas quando houver requisito funcional real.
